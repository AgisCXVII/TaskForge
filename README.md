# CrossPost

**CrossPost** is a lightweight task tracker focused on quick entry, visual prioritization, and live countdowns. It lets you create tasks with time frames, colors, and notes so you can keep momentum while watching time tick down.

## Development Status

CrossPost is still in development, and progress is steady now that the web app is considered ready at its base. Expect refinements and new capabilities as the experience continues to evolve.

## Features

- **Task Capture:** Add tasks with a description, time frame, color, and optional notes.
- **Live Countdown:** Track remaining time with a real-time timer for each task.
- **Visual Priorities:** Use color accents to quickly scan task importance.
- **Completion Tracking:** Mark tasks complete or remove them when finished.
- **Focused Interface:** A clean layout keeps the workflow straightforward.

## Installation

To get started with CrossPost on your local machine:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/username/crosspost.git
   ```
2. **Navigate to the Project Directory**
   ```bash
    cd crosspost
   ```
3. **Install Dependencies**
   *Make sure you have Node.js and npm installed. Then, run:*
   ```bash
   npm install
   ```
4. **Start the Application**
   ```bash
   npm start
   ```

## Usage

- **Add a Task:** Enter a task description, time frame (e.g., `2h`, `30m`, `120s`, `1d`), choose a color, and add notes.
- **Track Time:** Use the live countdown to see how much time is left for each task.
- **Complete or Remove:** Use the checkbox to mark tasks as complete or delete them when done.
